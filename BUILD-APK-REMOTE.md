# Build APK otomatis

Workflow GitHub Actions tersedia di `.github/workflows/build-apk.yml`. Workflow membangun APK debug pada runner GitHub, tanpa perlu memasang Android Studio atau Android SDK di komputer.

Setelah workflow sukses, buka tab **Actions**, pilih run **Build Catatan Simpel APK**, lalu unduh artifact **CatatanSimpel-debug-apk**. File APK berada di dalam ZIP artifact dan artifact tersimpan selama 14 hari.
