# Catatan Simpel — Android native

Aplikasi catatan native Android berbasis Java, tanpa internet dan tanpa library pihak ketiga.

## Fitur
- Buat dan edit catatan
- Simpan otomatis ke penyimpanan lokal aplikasi (SharedPreferences)
- Cari catatan berdasarkan judul atau isi
- Tekan lama kartu catatan untuk menghapus
- Tampilan minimalis berbahasa Indonesia
- Android 6.0 (API 23) ke atas

## Build APK
Build APK debug menggunakan GitHub Actions. Buka tab Actions dan jalankan workflow **Build Catatan Simpel APK**. Setelah sukses, unduh artifact **CatatanSimpel-debug-apk**; file APK berada di dalam ZIP artifact.
